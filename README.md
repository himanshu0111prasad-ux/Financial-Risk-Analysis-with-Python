# Financial Data Analysis & Cleaning Pipeline 📊

A Python-based data analysis pipeline built to load, clean, process, and explore financial transactional datasets. 

---

## 🚀 Project Overview

The core objective of this project is to build an end-to-end data processing workflow for financial data. The pipeline handles data extraction, anomaly detection, data cleaning, and statistical exploration to ready records for advanced financial modeling.

---

## 🛠️ Tech Stack & Dependencies

* **Language**: Python 3.x
* **Libraries**:
  * `pandas` (Data manipulation & cleaning)
  * `numpy` (Numerical computations)
  * `matplotlib` & `seaborn` (Data visualization & exploratory analysis)

---

## 📂 Dataset Structure

The dataset contains structured financial metrics across **800 rows and 15 columns**, including:
* **TransactionID / CustomerID**: Unique tracking identifiers.
* **AccountType & TransactionType**: Categorization of accounts and transactional activities.
* **Product**: Financial products (e.g., Savings, Credit Card, Loans).
* **TransactionAmount & AccountBalance**: Monetary values and running ledger balances.
* **RiskScore & CreditRating**: Customer creditworthiness metrics.
* **TenureMonths**: Length of relationship with the firm.
